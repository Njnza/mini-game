# PixAssets Custom Textures Guide

You can design custom character pixel art or textures on https://pixassets.dev/studio/
and export them as PNG images to use directly in Zap Pets 3D!

### Supported Texture Files:
- `fox.png`   -> Custom texture for Spark Fox
- `bear.png`  -> Custom texture for Iron Bear
- `bunny.png` -> Custom texture for Frost Bunny

Place your exported PNG images into this directory (`games/zap-pets/assets/`).
The 3D game engine will automatically detect and map your pixel art onto the 3D pet models!
If no custom image is found, the engine renders beautiful procedural low-poly shaded materials by default.
